# 交通費計算ツール 利用ガイド

## 課題

事務所（福岡市西区周船寺、最寄り駅：周船寺駅）から、利用者・病院・施設を訪問する際の交通費を、
毎回手計算・都度検索するのは手間がかかる。また「電車を基本とし、電車ルートがない場合はバスで計算する」
という優先順位を毎回人が判断すると、計算方法にばらつきが出やすい。

## 対応方針

`docs/交通費計算.xlsx` に、以下の2シート構成の計算ツールを用意した。

- **運賃マスタ**：利用者・病院・施設ごとに、最寄り駅／バス停、周船寺駅からの経路メモ、
  電車運賃（片道）、バス運賃（片道）を登録しておくシート。
- **交通費計算**：目的地（運賃マスタに登録した名称）と訪問回数（往復回数）を選ぶだけで、
  往復交通費・合計交通費を自動計算するシート。**電車運賃が登録されていれば電車を優先し、
  電車運賃が未登録の場合のみバス運賃で計算する**（ご要望どおり、電車＞バスの優先順位）。

### 使い方

1. 「運賃マスタ」シートの空いている行に、新しい訪問先（利用者名・病院名・施設名）と、
   最寄り駅／バス停、経路メモ、電車運賃・バス運賃（黄色セル）を入力する。
   - 種別（利用者／病院／施設）はプルダウンから選択できる。
2. 「交通費計算」シートの「① 目的地を選択」で、登録した訪問先をプルダウンから選ぶ。
3. 「② 訪問回数（往復・回）」に訪問回数を入力する。
4. 「③ 利用交通手段（判定）」「片道運賃」「往復運賃」「④ 合計交通費」が自動計算される。
   - 電車運賃・バス運賃がどちらも未入力の場合は「要確認」と表示される。

## 記入済みの例

### 福岡大学病院

- 最寄り駅は**「福大前」駅**（福岡市地下鉄七隈線）。「福岡大学病院前」という駅名ではないので注意。
  福大前駅は福岡大学と福岡大学病院に挟まれた場所にあり、病院までは徒歩約1分。
- 経路：周船寺→（JR筑肥線）→姪浜→（福岡市地下鉄空港線 直通）→博多（同一駅構内で地下鉄七隈線に乗換）→福大前→（徒歩約1分）→福岡大学病院
  - 2023年3月の七隈線延伸により、空港線との乗換駅は天神南駅から博多駅（同一駅構内）に変わっている。
- **片道運賃：650円** → **往復1,300円**（訪問1回あたり）
  - 駅探の運賃検索結果に基づく、JR～地下鉄の連絡運賃込みの通し運賃。
  - 区間ごとの単独運賃（周船寺～博多570円＋博多～福大前300円）を単純合算すると870円になるが、
    これは実際の連絡運賃より高く出る誤った計算方法なので使用しないこと。
- バス利用時の経路・運賃は未確認（西鉄バスの主要系統は天神・姪浜・博多駅等が発着点で、
  周船寺駅から直行するバス系統は見つからなかった）

### 福岡徳洲会病院（未確定）

- 春日市須玖北4-5。最寄り駅（南福岡駅・笹原駅）から徒歩15～20分と遠く、電車のみでは到達できない。
- 経路案：周船寺→（JR筑肥線・地下鉄空港線）→博多→（JR鹿児島本線）→南福岡→（西鉄バス45系統・約8分・210円）→福岡徳洲会病院
- **運賃は未入力（要確認）**。周船寺～南福岡間はJR・地下鉄・JRと3社局にまたがる連絡運賃となり、
  区間ごとの単独運賃を単純合算すると実際の連絡運賃より高く出るおそれがあるため、
  このガイドでは正確な金額を算出していない。

上記の運賃は、公式サイトへの直接アクセスができない状態での検索結果に基づくため、
**実際に利用する前に一度、Yahoo!路線情報・駅探等の公式経路検索、またはICカードでの実乗車で
最終確認**することを推奨する。
