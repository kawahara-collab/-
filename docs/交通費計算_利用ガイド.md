# 交通費計算ツール 利用ガイド

## 課題

事務所（福岡市西区周船寺、最寄り駅：周船寺駅）から、利用者・病院・施設を訪問する際の交通費を、
毎回手計算・都度検索するのは手間がかかる。また「電車を基本とし、電車ルートがない場合はバスで計算する」
という優先順位を毎回人が判断すると、計算方法にばらつきが出やすい。

## 対応方針

`docs/交通費計算.xlsx` に、以下の2シート構成の計算ツールを用意した。

- **運賃マスタ**：利用者・病院・施設ごとに、最寄り駅／バス停、周船寺駅からの経路メモ、
  電車運賃（片道）、バス運賃（片道）を登録しておくシート。
- **交通費計算**：目的地（運賃マスタに登録した名称）と訪問回数（往復回数）を選ぶだけで、
  往復交通費・合計交通費を自動計算するシート。**電車運賃が登録されていれば電車を優先し、
  電車運賃が未登録の場合のみバス運賃で計算する**（ご要望どおり、電車＞バスの優先順位）。

### 使い方

1. 「運賃マスタ」シートの空いている行に、新しい訪問先（利用者名・病院名・施設名）と、
   最寄り駅／バス停、経路メモ、電車運賃・バス運賃（黄色セル）を入力する。
   - 種別（利用者／病院／施設）はプルダウンから選択できる。
2. 「交通費計算」シートの「① 目的地を選択」で、登録した訪問先をプルダウンから選ぶ。
3. 「② 訪問回数（往復・回）」に訪問回数を入力する。
4. 「③ 利用交通手段（判定）」「片道運賃」「往復運賃」「④ 合計交通費」が自動計算される。
   - 電車運賃・バス運賃がどちらも未入力の場合は「要確認」と表示される。

## 記入済みの例：福岡大学病院

「運賃マスタ」シートに、例として福岡大学病院を1件登録している。

- 最寄り駅は**「福大前」駅**（福岡市地下鉄七隈線）。「福岡大学病院前」という駅名ではないので注意。
  福大前駅は福岡大学と福岡大学病院に挟まれた場所にあり、病院までは徒歩約1分。
- 経路：周船寺→（JR筑肥線・福岡市地下鉄空港線 直通、乗換なし）→天神→（徒歩）→天神南→（福岡市地下鉄七隈線）→福大前→（徒歩約1分）→福岡大学病院
- 確認できた運賃：周船寺～天神間 570円（JR筑肥線270円＋地下鉄空港線300円）
- **未確認**：天神南～福大前間（地下鉄七隈線）の運賃、およびバス利用時の経路・運賃

このガイド作成時点ではネットワーク制限があり、Yahoo!路線情報・駅探等の公式運賃検索サイトへ
直接アクセスして最終確認ができなかったため、電車運賃・バス運賃の入力欄はあえて空欄にしてある。
そのため現時点では「③利用交通手段（判定）」が「要確認」と表示される。

## 未確認事項・要確認ポイント

- 上記「福岡大学病院」の最終的な片道運賃（電車・バス）
- 周船寺駅発でバスのみで行ける訪問先があるかどうか（西鉄バスの主要系統は天神・姪浜・博多駅等が
  発着点であり、周船寺駅から直行するバス系統は今回の調査では見つからなかった）
- 運賃改定があった場合、マスタシートの運賃を随時更新する運用にする必要がある

## 次のステップ案

- 実際に訪問する利用者・病院・施設が判明次第、「運賃マスタ」シートに随時追加していく
- 運賃は変更されることがあるため、年1回程度、公式サイトで最新運賃に更新することを推奨する
