# 成年後見登記事項証明書 請求時の入力効率化ガイド

## 課題

申請用総合ソフト(法務省 登記・供託オンライン申請システムの公式デスクトップアプリ)で成年後見登記事項証明書を請求する際、
毎回「請求者名・電話番号・住所」等を入力し直す必要があり、手間がかかっている。

## 対応方針

申請用総合ソフトには、過去に作成した申請・請求データを土台にして新規データを作成する機能がある。
これを使えば、請求者名・電話番号・住所など毎回変わらない項目は前回入力した内容がそのまま引き継がれ、
変更が必要な項目(被後見人の氏名など、案件ごとに異なる情報)だけを書き換えればよくなる。

### 手順(概要)

1. 申請用総合ソフトを起動し、「処理状況表示」または「申請書作成」の一覧画面を開く
2. 過去に作成した、成年後見登記事項証明書の請求データを一覧から選択する
3. 選択したデータを右クリック、またはツールバーから「複製して新規作成」に相当する操作を行う
   (バージョンにより「コピーして新規作成」「同一内容で新規作成」等、表記が異なる場合がある)
4. 複製された新しいデータでは、請求者名・電話番号・住所欄はそのまま複製されているので、
   案件固有の項目(被後見人の氏名・登記番号等、請求内容)だけを修正する
5. 内容を確認し、電子署名・送信を行う

### 請求者パターンが複数ある場合

請求者(申請者)情報が案件によって複数パターンある場合は、パターンごとに「ひな形」用のデータを
1件ずつ作成・保存しておくと、都度そのひな形を複製して使えるため効率的。

## 未確認事項・要確認ポイント

このガイド作成時、ネットワーク制限により法務省の公式サイト・操作手引書PDFへのアクセスができず、
最新版ソフトの正確なメニュー名称・ボタン名は確認できていません。以下を実際の画面で確認のうえ、
必要であれば本ドキュメントを修正してください。

- 上記「複製して新規作成」に相当する操作の正式なメニュー名・ボタン名
- ソフト自体に、請求者情報単体を「よく使う情報」として登録・呼び出しできる専用機能が
  別途用意されているかどうか(バージョンによって有無・名称が異なる可能性がある)
- 正式な手順は下記の公式ページ・操作手引書で確認するのが確実
  - 操作手引書ダウンロード: https://www.touki-kyoutaku-online.moj.go.jp/download_manual.html
  - 申請用総合ソフトによる申請・請求方法: https://www.touki-kyoutaku-online.moj.go.jp/flow/sogosoft/gaiyo.html
