# アガルート行政書士講座 受講期間切れ対策ガイド

## 課題

アガルートの行政書士講座は受講期間が定められており、期間が切れると講義を視聴できなくなる。
個人使用・実務の振り返り目的であっても、講義内容を後から参照できる形で残しておきたい。

## 重要な前提: 動画の複製・ダウンロードは規約違反

アガルートの[会員規約](https://www.agaroot.jp/kiyaku/)では、教材について

- 「方法、理由の如何を問わず、複製物を作成すること」
- 「教室内において講義内容等を収録(録画・録音等)すること」
- 「方法、理由の如何を問わず、第三者と共有すること」

を禁止している。「方法、理由の如何を問わず」と明記されているため、**個人使用や実務の振り返りという目的であっても、講義動画・音声のダウンロード・録画・複製は契約(利用規約)違反となる**。

ネット上には動画を保存するための第三者ツール・サービスを紹介するサイトもあるが、規約違反のリスクがあるため、本ガイドではそうした方法は扱わない。

(本ガイド作成時、ネットワーク制限により`agaroot.jp`ドメインへの直接アクセスができず、規約の正確な条文はWeb検索結果からの引用。最新かつ正確な内容は必ず公式ページで確認すること。)

## 規約の範囲内でできる代替策

### 1. USBメモリオプションの確認

講座によっては、教材を物理メディア(USBメモリ等)で受け取れる公式オプションが用意されている場合がある。
これは運営が正規に提供する手段であるため規約違反にならない。

- 行政書士講座の申込ページ・マイページでオプションの有無を確認する
- 既に申込済みの場合、追加購入が可能か事務局に問い合わせる

### 2. 受講期間の延長を問い合わせる

多くの予備校では、有償での受講期間延長プランが用意されていることがある。

- アガルートの[お問い合わせ窓口](https://www.agaroot.jp/)またはマイページのサポート窓口から、
  行政書士講座の受講期間延長オプションの有無・料金を確認する
- 延長ができれば、動画を複製せずとも必要なタイミングで再視聴できる

### 3. 自分の言葉でまとめた学習ノート・実務振り返りメモを作成する

講義動画そのものではなく、**自分が理解した内容を自分の言葉で要約したノート**を作成するのは、
著作物の複製にあたらず、実務の振り返り資料としてもむしろ有用。

- 各回の講義視聴時に、論点・要件・自分の実務でつまずきやすい点をその場でメモする
- 講義終了後、単元ごとに「学んだこと」「実務で使うときの注意点」を1〜2段落で要約し、
  `docs/`配下や個人のノートアプリに蓄積する
- 判例・条文番号など客観的事実は引用してよいが、講師の説明をそのまま書き写す(実質的な複製)は避け、
  自分の理解として言い換える

### 4. 配布テキスト・レジュメ(PDF)の保存

講座に**公式にダウンロード可能な形で提供されているテキスト・レジュメ**がある場合、
それは動画とは別に用意された配布教材であり、マイページの機能内でダウンロードできる範囲であれば
利用目的の範囲内(個人の学習用)として保存して問題ない。

- マイページの教材ダウンロード機能から、PDFテキスト・レジュメを保存しフォルダ整理する
- 保存後も、他者への共有・アップロードは規約で禁止されているため行わない

## 未確認事項・要確認ポイント

- USBメモリオプション・受講期間延長オプションが、現在申込中の行政書士講座で実際に用意されているか
  → [公式サイト](https://www.agaroot.jp/)・マイページ・事務局への問い合わせで確認
- 会員規約の禁止事項の正確な条文(本ガイドはWeb検索結果からの引用)
  → [会員規約ページ](https://www.agaroot.jp/kiyaku/)で原文を確認

## 次のステップ案

- 事務局への問い合わせ結果(延長可否・USBオプション有無)が分かれば、本ガイドに反映する
- 学習ノートの蓄積方法(ファイル命名規則・保存場所)を決め、単元ごとのテンプレートを用意すると
  実務振り返り資料として運用しやすくなる
