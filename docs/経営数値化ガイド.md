# 経営数値化ガイド

## 課題

日々の業務(申請・請求対応など)に追われる中で、事務所全体の経営状態が
「感覚」でしか把握できておらず、以下のような判断が数値の裏付けなしに行われがちになる。

- 今月・今期の売上や利益が、締めてみるまで正確に分からない
- どの業務(案件種別)が実際に儲かっているのか分からない
- 相談件数に対して、どれくらい受任・成約につながっているのか分からない
- 担当者ごとの案件数・稼働状況にばらつきがあっても気づきにくい
- 資金繰り(入金・支払いのタイミング)の見通しが立てにくい

これらを毎月決まった指標として数値化し、定点観測できる状態にすることが目的。

## 対応方針

高度な会計システムを新規導入しなくても、既存のExcel/スプレッドシートと
月次の集計フローだけで最低限の経営数値化は可能。まずは「少ない指標を、毎月必ず見る」
ことを優先し、運用が定着してから指標や自動化を拡張していく。

### 1. 最低限追うべき指標(KPI)の候補

| カテゴリ | 指標 | 算出方法(目安) |
| --- | --- | --- |
| 売上・利益 | 月次売上高 | 当月請求(成約)ベースの合計 |
| 売上・利益 | 業務種別ごとの売上構成比 | 業務種別ごとの売上 ÷ 月次売上高 |
| 売上・利益 | 粗利・営業利益 | 売上 − 直接原価(外注費・実費等) / さらに固定費を控除 |
| 案件獲得 | 相談件数 | 月内の新規相談・問い合わせ件数 |
| 案件獲得 | 受任率(成約率) | 受任件数 ÷ 相談件数 |
| 案件獲得 | 1件あたり平均単価 | 月次売上高 ÷ 受任件数 |
| 生産性 | 担当者別案件数・処理件数 | 担当者ごとの受任中/完了件数 |
| 資金繰り | 未回収金額(売掛) | 請求済み・未入金の合計額 |
| 資金繰り | 翌月以降の入金予定額 | 契約済み案件の入金予定日ベースで集計 |

事務所の業態(相談・受任型か、行政手続の代行が中心かなど)に応じて、
上表から優先度の高いものを3〜5個に絞って始めるのが現実的。指標を増やしすぎると
集計自体が負担になり、続かなくなる点に注意。

### 2. 運用の型(月次サイクル)

1. 案件管理表(既存のExcel・申請用総合ソフトの処理状況一覧など)から、
   当月の「相談件数」「受任件数」「請求(売上)金額」を書き出す
2. 上記の指標一覧(経営数値シート)に転記し、前月・前年同月と並べて比較できる形にする
3. 月初の定例会議やミーティングで、数値を見ながら
   「先月と比べて増減した理由」「気になる指標」を確認する
4. 数値が悪化した指標があれば、原因(相談件数減・受任率低下・単価低下など)を
   切り分けて対応策を検討する

### 3. 集計元データの一元化

既存業務で使っているツール(申請用総合ソフトの処理状況一覧、顧客管理表、
請求書発行ツールなど)から、月次で手作業転記する運用でも開始できる。
ただし転記ミス・抜け漏れを防ぐため、以下を推奨する。

- 「案件ごとに、相談日・受任日・請求日・入金日を必ず記録する」ルールを決め、
  1つの案件管理表(またはスプレッドシート)に集約する
- 経営数値シートの各指標は、可能な限り関数(SUMIFS等)で自動集計し、
  手計算・転記ミスを減らす

## 未確認事項・要確認ポイント

- 事務所で現在使用している会計ソフト・請求書発行ツール・案件管理表の有無と形式
  (Excelか、専用システムか)が未確認のため、上記は汎用的な運用案としている
- どの業務種別(相談種別)ごとに売上を分けて管理したいか、事務所側での分類定義が必要
- 固定費(家賃・人件費等)の扱いを含めた「利益」の定義は、顧問税理士等と
  すり合わせたうえで確定するのが望ましい

## 次のステップ案

- 実際に使っている案件管理表・請求データのフォーマットを確認し、
  経営数値シートへの自動集計(SUMIFS等)のテンプレートを作成する
- 優先指標を3〜5個に絞り込み、直近数か月分を試験的に遡って数値化し、
  運用に無理がないか検証する
- 運用が定着した後、必要に応じてダッシュボード化(グラフ化)や
  会計ソフト連携による自動化を検討する
