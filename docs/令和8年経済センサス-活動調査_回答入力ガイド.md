# 令和8年経済センサス-活動調査 回答入力ガイド

## 状況

一般社団法人 かわはら社会福祉士事務所(福岡市西区周船寺、調査区番号0116・事業所番号6006)宛に、
福岡市西区役所および総務省統計局・経済産業省の連名で、「令和8年経済センサス-活動調査」の
調査票が未提出であるとの督促状(令和8年8月24日付)が届いている。

この調査は統計法(平成19年法律第53号)に基づく**報告義務のある基幹統計調査**であり、
督促状が届いている以上、至急対応が必要な状態。

- 調査期日: 令和8年6月1日現在
- 督促状の日付: 令和8年8月24日(本日令和8年8月28日時点で提出期限を過ぎている)
- 対象: 全国の全事業所・企業

## 回答方法

督促状に記載の「政府統計コード」「調査対象者ID」「パスワード」を使って、
政府統計オンライン調査システム(実施事務局サイト: https://www.e-census-st.go.jp/online/ 、
または キャンペーンサイト https://www.e-census2026.go.jp/ 経由)からインターネット回答する。

- 24時間いつでも回答可能
- パソコン(デスクトップ/ノートPC)での回答を推奨。スマートフォン・タブレットは非推奨
- macOSの場合は「HTML調査票」を使用する(「Excel調査票」はmacOS非対応)
- e-Taxで確定申告済みの場合、確定申告データを取り込んで一部自動入力できる仕組みがある
  (調査票の種類が【01】調査票(産業共通)の場合)

### 入力手順(概要)

1. 案内状記載の「政府統計コード」「調査対象者ID」「パスワード」でオンライン回答システムにログイン
2. 案内に従い、該当する調査票の種類を選択・確認する
3. 基本項目(事業所名・所在地・電話番号・法人番号など)を入力・確認する
4. 産業分類に応じた実態項目(事業内容、従業者数、年間の収入・費用等)を入力する
5. 入力内容を確認し、送信する

### 事前に準備しておくとよい情報

- 直近事業年度の年間収入・費用等の概要
- 従業者数(役員・パート含む)
- 事業内容の具体的な説明(社会福祉士事務所としての業務内容)
- 法人の開設(設立)年月日、資本金等
