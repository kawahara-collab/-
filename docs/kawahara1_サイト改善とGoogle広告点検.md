  - Googleアナリティクスから取り込んだ「ページを見た」などの軽い行動
- **確認：** 8月・9月に実際に届いた問い合わせ件数と、31件・16件を比べてください。合わなければ、数え方が間違っています。

**② 配信先がずれている可能性が高い（推定）**

## 3. 今日すぐできる修正（グーペ管理画面）

グーペの管理画面のメニュー名は、契約しているプランや時期によって違うことがあります。

### A. 電話番号を押して電話をかけられるようにする
- `docs/goope/welcome.html` には、電話番号を押して電話をかけられるボタンが入っています。スマホでは、画面下に常に表示される電話ボタンも出ます。
- 貼り付けるだけで、トップページは対応できます。
- 他のページのヘッダーにある電話番号は、テーマ側の表示で、今は文字だけです。グーペの「ナビゲーションパーツ（サイドバーなどにHTMLを置ける場所）」に、次のHTMLを追加すると全ページで押せるようになります。

```html
<a href="tel:0120862944" onclick="gtag('event','conversion',{'send_to':'AW-797252503/XXXXXXXXXX'});"
   style="display:block;background:#1d3557;color:#fff;text-align:center;padding:14px;font-weight:700;text-decoration:none;">
  電話で相談 0120-86-2944<br><span style="font-size:12px;font-weight:400;">平日 9:00–17:00</span>
</a>
```

### B. 重複したタグと不要なタグを消す
1. **ナビゲーションパーツ**にある、次のGoogle広告タグを削除します。同じものが `<head>`（ページの先頭部分）にも入っているので、二重になっています。
   ```html
   <script async src="https://www.googletagmanager.com/gtag/js?id=AW-797252503"></script>
   ...gtag('config', 'AW-797252503');
   ```
2. `<head>` にある次の1行を削除します。
   ```html
   <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js"></script>
   ```
   これはAdSense（自分のサイトに他社の広告を出して収入を得る仕組み）のタグです。事務所のサイトには不要で、設定によっては同業他社の広告が表示されてしまいます。
3. `<head>` に残すのは、次の構成です（今の形のままで大丈夫です）。
   ```html
   <script async src="https://www.googletagmanager.com/gtag/js?id=G-JB5F3GZMWN"></script>
   <script>
     window.dataLayer = window.dataLayer || [];
     function gtag(){dataLayer.push(arguments);}
     gtag('js', new Date());
     gtag('config', 'G-JB5F3GZMWN');
     gtag('config', 'AW-797252503');
   </script>
   ```

## 4. 一流企業風へのリニューアル手順（グーペ）

### 4-1. 方針
- **色**：藍（濃い紺）を主色に、可也山の夕景をイメージした柿渋色を差し色にします。白い余白を広く取ります。
- **文字**：見出しは明朝体（しっぽり明朝）、本文はゴシック体（Zen角ゴシック）にします。信託銀行や老舗法人のような落ち着いた格を出すためです。
- **構成**（トップページを上から順に）：
  1. 結論となる一文と電話ボタン
  2. 実績の帯
  3. このようなお悩み
  4. 強み3つ
  5. 業務と費用
  6. 相談の流れ
  7. 代表メッセージ
  8. よくあるご質問
  9. 事務所概要
  10. 問い合わせ
- **残すもの**：**筆文字のロゴ「一般社団法人かわはら社会福祉士事務所」はそのまま使い続ける**（オーナー様のご希望）。デザイン案では文字で仮置きしているので、再開時に筆文字ロゴの画像に差し替える。
- **やめるもの**：ツタの装飾、アクセスカウンター、QRコード、筆記体の英字見出し（welcome / information）

### 4-2. 作業手順
1. **テーマを変える**
   - デザイン → テーマ選択で、装飾の少ないシンプルなテーマに変えます（白地・1カラムのもの）。
   - 変える前に、今のテーマ名を控えておくと、元に戻せます。
2. **CSSを貼る**
   - デザイン → CSS（スタイルシート）編集の末尾に、`docs/goope/custom.css` の全文を貼ります。
3. **トップページの本文を置き換える**
   - トップページ → ウェルカムメッセージを「HTML（ソース）」表示に切り替え、`docs/goope/welcome.html` の全文で置き換えます。
   - 今の本文は、念のため控えておいてください。
4. **スライド画像を減らす**
   - 6枚あるスライドを1〜2枚にします。おすすめは、可也山の夕景の写真と、事務所の外観またはスタッフの写真です。
   - 「ようこそ」「世代をこえて」などの文字入り画像は外します。
5. **メニューを整理する**（ナビゲーションの順番と名前）
   1. トップ
   2. 業務内容と費用（業務MENU）
   3. ご相談の流れ（業務MENU内に追加、またはフリーページ）
   4. 代表挨拶
   5. スタッフ
   6. 事務所概要・アクセス
   7. よくあるご質問（フリーページを新しく作る）
   8. ブログ
   9. お問い合わせ

   「社訓」「カレンダー」「成年後見制度について資料」は、メインメニューから外してフッター（ページ最下部）に移します。
6. **3章 C のタイトル・説明文**を各ページに設定します。
7. **スマホで確認する**
   - 電話ボタンを押して、発信画面が開くかを確認します。
   - フォームのテスト送信をして、完了ページのURLを控えます（2-3の2で使います）。

### 4-3. 写真について（信頼感を左右します）
- 代表とスタッフは、**プロのカメラマンによる統一したトーンの写真**にすることを強くおすすめします。目安は1〜3万円程度です。
- 事務所の入口と相談室の写真も1枚ずつあると、「行っても大丈夫な場所だ」と伝わります。
