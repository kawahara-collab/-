# 試用期間中の解雇 対応ガイド

## 課題

試用期間中の従業員について、勤怠不良・能力不足・経歴詐称などを理由に雇用契約を終了させたいという
相談を受けた際、本採用後の解雇と何が違うのか、どのような手順・書面を踏めば法的リスクを抑えられるか
が整理されておらず、都度調べ直しになっている。

## 前提となる法的位置づけ

- 試用期間中の労働契約は、判例上「解約権留保付労働契約」と位置づけられる(最高裁・三菱樹脂事件 昭和48年12月12日判決)。
  すなわち、試用期間中であっても労働契約は既に成立しており、無条件にいつでも自由に解雇できるわけではない。
- 解雇には労働契約法第16条(解雇権濫用法理)が適用され、「客観的に合理的な理由」「社会通念上相当」であることが必要な点は
  本採用後の解雇と同様。ただし試用期間は労働者の適性を見極める期間という性質上、本採用後の解雇よりは
  広い範囲で解雇の合理性が認められやすい傾向がある(採用時に知り得なかった事情が試用期間中に判明した場合など)。
- 労働基準法第21条により、**試用期間開始から14日以内**の解雇であれば、同法第20条の解雇予告(30日前予告)・
  解雇予告手当の規定は適用されない。**14日を超えて雇用した後**に解雇する場合は、試用期間中であっても
  通常の解雇と同様に30日前の予告、または不足日数分の平均賃金(解雇予告手当)の支払いが必要。
- 労働基準法第22条により、労働者から請求があった場合は解雇理由証明書を交付する義務がある。
  試用期間中・本採用拒否のいずれの場合も、解雇理由は具体的な事実に基づいて記載する必要がある。

## 対応方針

以下の順序で、証拠(記録)を残しながら段階的に対応する。

### 手順(概要)

1. **事実の記録**: 遅刻・欠勤・業務指示違反・成果不足などの具体的な事実を、日時・内容が分かる形で
   都度記録しておく(口頭注意のみで終わらせない)。
2. **注意・指導と改善機会の付与**: 問題行動について書面または記録に残る形で注意・指導を行い、
   改善のための一定期間を与える。改善計画書・指導記録を作成しておくと、後日「社会通念上相当」であった
   ことを説明しやすくなる。
3. **試用期間の延長の要否検討**: 就業規則に試用期間延長規定がある場合、判断保留のため延長する選択肢も
   検討する(無制限の延長は権利濫用とされ得るため、規定上限内で行う)。
4. **解雇(本採用拒否)の判断**: 改善が見られない場合、就業規則の解雇事由・試用期間に関する規定を確認した上で、
   解雇(または本採用拒否)を決定する。
5. **予告・手当の確認**: 雇用開始から14日以内かどうかを確認し、14日を超えている場合は30日前予告または
   解雇予告手当の準備をする。
6. **解雇理由の書面化**: 解雇通知書を作成し、具体的な解雇理由(就業規則上の根拠条文を含む)を記載する。
   労働者から解雇理由証明書の請求があった場合は速やかに交付する。
7. **社会保険・雇用保険の資格喪失手続き**: 退職に伴う社会保険・雇用保険の資格喪失届等、通常の退職手続きを行う。

## 未確認事項・要確認ポイント

本ガイドは一般的な法的枠組みの整理であり、個別事案への当てはめではない。実際の対応にあたっては
以下を確認すること。

- 対象企業の就業規則における試用期間の長さ・延長規定・解雇事由の具体的な定め
- 解雇理由が「経歴詐称」など採用時に知り得なかった事情に該当するか、それとも通常の能力不足等に
  該当するかによって、必要な立証の程度が変わり得る点
- 個別の事実関係が複雑な場合、または労働者側から異議・あっせん・労働審判等に発展するおそれがある場合は、
  社会保険労務士・弁護士へ相談の上で最終判断すること(本ガイドは実務の見取り図であり、法的助言の代替ではない)

## 次のステップ案

- 就業規則のひな形に試用期間・解雇事由に関する条文が整備されているか確認し、不足があれば追記を検討する
- 注意指導記録・改善計画書のテンプレートを別途整備し、日々の記録を標準化する
- 解雇通知書・解雇理由証明書のひな形を作成し、本ガイドの手順から直接参照できるようにする
