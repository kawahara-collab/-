# 弥生会計(デスクトップ版) スマート取引取込 運用ガイド(法人・個人 二事業所管理)

## 前提

- 弥生会計はデスクトップ版を使用
- スマート取引取込(銀行・カード明細の自動取込機能)を利用
- 法人・個人の2つの事業所データ(会計帳簿)を、同じPC上で並行して管理している

## 課題

法人・個人それぞれの事業所データに、スマート取引取込で明細を取り込んで仕訳登録する運用において、

- どちらの事業所データに取り込んでいるかを取り違えないこと
- 取り込んだ取引の科目・摘要を都度手作業で直さず、必要な情報をすぐ探し出して効率よく処理すること

が課題になる。以下に、デスクトップ版弥生会計における基本的な考え方と手順をまとめる。

## 事業所データは法人・個人で別ファイル

弥生会計では「事業所データ」が1つのファイルとして保存される(1ファイルに3期分のデータが入る)。**法人と個人は科目体系(勘定科目)が異なるため、必ず別の事業所データとして作成・管理する。**

- 個人の事業所データ作成時: 科目体系を「個人/一般」「個人/農業」「個人/不動産」から選択し、氏名・屋号(事業所名)を入力する
- 法人の事業所データ作成時: 事業所名・法人番号を入力する
- 作成: クイックナビゲータの[導入](または[スタート])カテゴリ→[データの新規作成]、もしくは[ファイル]メニュー→[新規作成]→「新規にデータを作成する」

複数の事業所データを開いている・保存している場合、**現在どちらの事業所データを開いて作業しているかを、弥生会計の画面上(タイトルバー/事業所名表示)で必ず確認してから**スマート取引取込を実行する。取り違えると、法人の経費が個人側に、個人の経費が法人側に混入してしまい、後から仕訳を探して移動する手間が発生する。

## スマート取引取込の基本フロー

1. 弥生会計で対象の事業所データを開く(法人 or 個人、取り違えに注意)
2. スマート取引取込を起動し、連携している金融機関・カードから明細を受信する
3. 受信した明細は、仕訳の学習機能によって科目が自動で推測され、[未確定の取引]画面に一覧表示される
4. [未確定の取引]画面で、各取引の科目・摘要・税区分などを確認する。自動推測が誤っている場合は手動で修正する
5. 取り込む取引にチェックを付ける(全選択も可能)。チェックのない取引は確定されない
6. [選択された取引の操作を行う]から取引データを確定すると、開いている事業所データ側に仕訳として登録される
7. 登録後は弥生会計の仕訳日記帳などで反映内容を確認する

## 修正内容を「仕訳ルール」として登録し、次回以降を自動化する

同じ取引先・同じ内容の明細は、毎回手作業で科目を直すのではなく「仕訳ルール設定」に登録しておくと、次回以降の取込で自動的に正しい科目・摘要が割り当てられるようになる。

- スマート取引取込の[設定]メニュー→[仕訳ルール設定]から、条件(取引先名や金額パターンなど)と、割り当てたい科目・摘要をあらかじめ登録できる
- あるいは、[未確定の取引]画面や仕訳日記帳で科目・摘要を修正した後、その修正結果を仕訳ルールとして追加登録することもできる
- 仕訳ルールは事業所データ(法人/個人)ごとに紐づくため、**法人用のルールと個人用のルールは別々に育てていく**必要がある。よく出てくる取引(家賃・通信費・カード引き落としなど)から優先してルール化すると、都度の確認作業が減る

## 必要な情報をすぐ探し出すための確認ポイント

日々のサポート(内容確認・不明点の調査)でよく参照する画面は次のとおり。

- **未確定の取引が表示されない/取り込めない** → 連携している金融機関側の明細取得期間、連携設定(ID・パスワードの有効期限切れなど)を確認する
- **取引がどちらの事業所データに登録されたか分からない** → 各事業所データの仕訳日記帳・元帳を日付・金額で検索して確認する
- **同じ取引が重複して取り込まれた** → 確定済みの取引一覧および仕訳日記帳で、同一日付・同一金額の重複がないか確認し、重複分は仕訳を削除する
- **科目の割り当てが毎回おかしい** → 仕訳ルール設定を見直し、条件が別の取引と衝突していないか確認する
